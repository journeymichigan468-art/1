Remote Desktop Protocol

Windows 11 Remote Desktop via GitHub Actions

About This Project

This project provides GitHub Actions workflows that create temporary Windows 11 virtual machines with remote desktop access. It uses:

  • Tailscale - Secure mesh VPN for connectivity
  • RustDesk - Open-source remote desktop software
  • Chrome Remote Desktop - Optional additional access method

Important Notice

This project runs on GitHub Actions, not on Replit. The workflows must be triggered from the GitHub repository's Actions tab.

Available Workflows

RDP + Tailscale + RustDesk (A/B)

Creates Windows 11 VMs with RDP access via Tailscale. Supports up to 10 parallel instances.

Stop Workflow

Cleans up and removes devices from Tailscale network.

How to Use

  1. Fork this repository on GitHub
  2. Go to the Actions tab in your forked repo
  3. Select a workflow to run
  4. Enter your Tailscale credentials and configuration
  5. Click "Run workflow"
  6. Connect using the provided credentials

Required Credentials

  • Tailscale Tailnet - Your Tailscale account (e.g., you@gmail.com)
  • Tailscale API Key - Device admin API key
  • Tailscale Auth Key - Reusable or ephemeral auth key
